ENVIO DE CORREOS MULTIPLES CON PLANTILLAS
El proyecto "Envio de correos multiples con plantillas" tiene como obetivo optimizar el proceso de envio masico y correos electronicos mediante la aplicacion de los patrones de diseño singleton y object pool. Este sistema simula el envio automatizado de mensajes personalizados utilizando plantillas que ya se encuentran prediseñadas y de esta forma garantizando una gestion eficiente de los recursos y un control centralizado de las operaciones. Gracias a la combinacion de ambos patrones, el programa logra una alta eficiencia, escalabilidad y reutilizacion de recursos, facilitando el manejo simultaneo de multiples correos sin perder consistencia ni rendimiento.
